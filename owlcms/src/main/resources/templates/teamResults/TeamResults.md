# TeamResults Templates — JXLS3 Template Structure

Generated by `generate-team-results-template.py` in this directory.

Two variants are produced (identical content, different paper size):
- `TeamResults-A4.xlsx` — A4 landscape
- `TeamResults-Letter.xlsx` — US Letter landscape

## Sheets

| Index | Name  | Bean list      | Gender key |
|-------|-------|----------------|------------|
| 0     | Men   | `mTeamItems`   | Gender.M   |
| 1     | Women | `wTeamItems`   | Gender.F   |
| 2     | Mixed | `mwTeamItems`  | Gender.MF  |

Empty sheets (no teams for that gender) are removed by `JXLSTeamResultsSheet.postProcess()`.

## Row layout (each sheet identical)

| Row | Cols  | Content | JXLS comment |
|-----|-------|---------|--------------|
| 1   | A     | `${competition.competitionName}` | `jx:area(lastCell="G7")` |
| 2   | A, D  | Championship name; ageGroupPrefix + gender label | — |
| 3   | A–G   | Team summary: name, points (conditional), counted/size, score (conditional) | `jx:each(items="XXTeamItems" var="team" lastCell="G7")` |
| 4   | A–G   | Column headers (#, Name, Category, Points, Done, scoring title) | — |
| 5   | A–G   | Member row: name, gender, category, points, done, score | `jx:each(items="team.sortedTeamMembers" var="member" lastCell="G5")` |
| 6   | A     | Spacer (inside outer loop) | — |
| 7   | A     | Empty row (end of jx:area) | — |

## Per-sheet display control

Each sheet uses a prefix (`m` / `w` / `mw`) for its display beans:

| Bean | Type | Description |
|------|------|-------------|
| `mShowPoints` / `wShowPoints` / `mwShowPoints` | `Boolean` | true when points-based, false when score-based |
| `mScoringTitle` / `wScoringTitle` / `mwScoringTitle` | `String` | Score column heading (e.g. "GAMX", "Total") |

### Team summary row (row 3) visibility

- **Points (col E)**: shown only when `xxxShowPoints` is true; zeros hidden
  - `${mShowPoints && team.points != 0 ? team.points : ""}`
- **Score (col G)**: shown only when `xxxShowPoints` is false (score-based); zeros hidden
  - `${!mShowPoints && team.score != 0 ? team.score : ""}`

### Member row (row 5) visibility

- **Points (col E)**: always shown (individual place points); zeros hidden
  - `${member.points != null && member.points != 0 ? member.points : ""}`
- **Score (col G)**: always shown; zeros hidden; formatted as `0.00`
  - `${member.score != null && member.score != 0 ? member.score : ""}`

## Beans provided by JXLSTeamResultsSheet

| Bean | Type | Description |
|------|------|-------------|
| `mTeamItems` | `List<TeamTreeItem>` | Men's teams (only if non-empty) |
| `wTeamItems` | `List<TeamTreeItem>` | Women's teams (only if non-empty) |
| `mwTeamItems` | `List<TeamTreeItem>` | Mixed teams (only if non-empty) |
| `mShowPoints` / `wShowPoints` / `mwShowPoints` | `Boolean` | Per-sheet points visibility |
| `mScoringTitle` / `wScoringTitle` / `mwScoringTitle` | `String` | Per-sheet score column label |
| `competition` | `Competition` | Competition object |
| `championship` | `Championship` | Selected championship (may be null) |
| `ageGroupPrefix` | `String` | Selected age group prefix (may be null) |
| `t` | translations map | `t.get("key")` for i18n |

## TeamTreeItem accessors (team-level)

`getName()`, `getGender()`, `getPoints()` (int), `getScore()` (double),
`getCounted()`, `getSize()`, `getSortedTeamMembers()` → list of member items.

## TeamTreeItem accessors (member-level)

`getName()`, `getGender()`, `getCategory()`, `getPoints()` (Integer, null if not done),
`getScore()` (Double), `isDone()`.

## Scoring override

When a gender group uses points-based ranking (Sum of Points), the tree is built with
`Ranking.TOTAL`, then `overrideScoringSystem()` re-sets each team and member scoring to
`championship.getBestAthleteScoringSystem()` (e.g. GAMX) so the score column displays
the correct athlete scoring values instead of total kg.

## Sorting

- Points-based groups (M/W when "Sum of Points"): sorted by `pointComparator` (points descending)
- Score-based groups (when "Sum of Scores"): sorted by `scoreComparator` (score descending)
- Each gender group uses its own comparator based on its own championship setting.
