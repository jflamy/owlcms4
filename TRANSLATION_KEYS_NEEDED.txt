Translation Keys Required for ClearWeighIn Feature
===================================================

The following translation keys need to be added to translation4.csv through the external translation management system:

1. ClearWeighIn
   English: "Clear Weigh-In"
   Description: Button label to clear weigh-in data (bodyweight and declarations)
   
2. Warning_WeighIn
   English: "Beware: this will clear the body weights and starting weight declarations (snatch and clean & jerk) from the selected athletes"
   Description: Warning message shown in confirmation dialog
   
3. WeighInCleared
   English: "Weigh-in data has been cleared."
   Description: Success message after clearing weigh-in data

Context:
--------
This feature was created to replace the "Clear Body Weights" button with a more comprehensive
"Clear Weigh-In" button that clears:
- Body weight
- Snatch first attempt declaration
- Clean & Jerk first attempt declaration

The feature only applies to athletes visible after grid filtering (using athletesFindAll(false)).

Files Modified:

  - Updated button and confirmation dialog to use new translation keys
  
- owlcms/src/main/java/app/owlcms/data/athlete/Athlete.java

DO NOT manually edit translation4.csv - use the external translation management system.
