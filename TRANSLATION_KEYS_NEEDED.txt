# Translation Keys for IWF Team Assignments (Timetable) Feature

## TSV Files to Import

### File: shared/src/main/resources/i18n/timetable_translations.tsv

Contains 13 new translation keys for the timetable import/export feature:

1. **TechnicalOfficial.OfficialRole** - Label for the OfficialRole field in technical official edit form
2. **OfficialRole.REFEREE** - Translation for REFEREE enum value
3. **OfficialRole.JURY_MEMBER** - Translation for JURY_MEMBER enum value
4. **Timetable.IWFTeamAssignments** - Section header for IWF Team Assignments timetable UI
5. **Timetable.ExportTimetable** - Button label to export timetable to CSV
6. **Timetable.ImportTimetable** - Button label to import timetable from CSV
7. **Timetable.SelectCSVFile** - Upload dialog instruction text
8. **Timetable.ImportFailed** - Error message when timetable import fails
9. **Timetable.UploadFailed** - Error message when file upload fails
10. **Timetable.ImportedSuccessfully** - Success message after import
11. **Timetable.NoEntriesFound** - Warning message when CSV contains no valid entries
12. **Timetable.entries** - Plural form noun for timetable entries in success message

## Session Assignment Generation

The "Generate Session Assignments" feature:
- Reads the timetable to determine which officials are on which teams for which sessions
- Implements rotation logic for referees and jury members
- Creates SessionAssignment records linking officials to specific positions in each session

**Referee Rotation** (center → reserve → right → left → center):
- 4-member teams: CENTER_REFEREE → REFEREE_RESERVE → RIGHT_REFEREE → LEFT_REFEREE → CENTER_REFEREE
- 3-member teams: CENTER_REFEREE → RIGHT_REFEREE → LEFT_REFEREE → CENTER_REFEREE (no reserve)

**Jury Rotation** (if reserve exists):
- 5+ member teams: D → RESERVE, A → B, B → C, C → D, RESERVE → A
- Smaller teams: No rotation (static positions A, B, C, D)
- Jury President does not rotate

## CSV Format

Timetable CSV uses 3 columns:
- Session (name of the group/session)
- Role (OfficialRole enum name: REFEREE, JURY_MEMBER, etc.)
- TeamNumber (numeric team ID: 1, 2, 3, 4)

Example:
```
Session,Role,TeamNumber
SessionA,REFEREE,1
SessionA,JURY_MEMBER,2
SessionB,REFEREE,1
SessionB,JURY_MEMBER,2
```

## Notes

- All enum values follow the pattern: `OfficialRole.{ENUM_NAME}` for translation keys
- Timetable feature translations follow the pattern: `Timetable.{feature}` for consistency
- Default language is English (en column in TSV file)
- All other languages fall back to English if translation is not provided
