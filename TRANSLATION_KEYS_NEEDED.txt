Translation Keys Required

1. ClearWeighIn Feature
------------------------

The following translation keys need to be added to translation4.csv through the external translation management system:

1. ClearWeighIn
   English: "Clear Weigh-In"
   Description: Button label to clear weigh-in data (bodyweight and declarations)
   
2. Warning_WeighIn
   English: "Beware: this will clear the body weights and starting weight declarations (snatch and clean & jerk) from the selected athletes"
   Description: Warning message shown in confirmation dialog
   
3. WeighInCleared
   English: "Weigh-in data has been cleared."
   Description: Success message after clearing weigh-in data

Context:
This feature was created to replace the "Clear Body Weights" button with a more comprehensive
"Clear Weigh-In" button that clears:
- Body weight
- Snatch first attempt declaration
- Clean & Jerk first attempt declaration

The feature only applies to athletes visible after grid filtering (using athletesFindAll(false)).

  - Updated button and confirmation dialog to use new translation keys
  
- owlcms/src/main/java/app/owlcms/data/athlete/Athlete.java
  - Added new clearWeighIn() method that clears bodyweight and declarations


2. V2 Export Feature
---------------------

### Translation Files Created:

A TSV file has been created with the new translation key:
**File**: shared/src/main/resources/i18n/new_v2_export_translations.tsv

This TSV file contains:
- Header row matching the exact language column sequence from translation4.csv
- One row with the new translation key with translations in all supported languages
- Tab-delimited format (not CSV)

### Translation Key Details:

1. ExportDatabase.DownloadJsonV2
   English: "Export Database V2"
   Description: Button label for V2 format database export (uses names/codes instead of IDs, numeric lifts)
   
### Context:

This feature adds an alternative JSON export format (V2) that:
- Uses human-readable names/codes instead of database IDs for references
- Renames "Group" to "Session" in the export
- Uses Integer values for lifts instead of String (null for empty)
- Includes formatVersion field for automatic detection during import

The V2 export button appears only when the "v2Export" feature switch is enabled.
It is placed after the standard "Export Database" button on the Prepare Competition page.
